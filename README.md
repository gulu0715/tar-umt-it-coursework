# TAR UMT IT Coursework

A collection of selected IT coursework projects, organised by project and technology. Each project has its own README with setup instructions, features and technical notes.

## Portfolio note

These projects were originally developed locally as part of TAR UMT coursework and later organised and uploaded to GitHub for portfolio presentation. The visible commit history therefore reflects repository publication and subsequent maintenance, not the original day-to-day development timeline.

## Projects

### [Study Room Booking System](study-room-booking/)

A PHP and MySQL web application for campus study-room reservations, with an AWS deployment target documented in the project README. This remains a team academic project; my contribution focused on the main technical implementation and AWS deployment/configuration work.

**Technologies:** PHP, MySQL, HTML, CSS, JavaScript, AWS EC2, Application Load Balancer, Auto Scaling, RDS, VPC, WAF and CloudWatch.

### [Python Expense Tracker](python-expense-tracker/)

A Tkinter desktop application for recording and managing expenses, with category and date-range filtering and local text-file persistence. A small launcher is included so the separated project can be run directly.

**Technologies:** Python, Tkinter, local file handling.

### [Java Car Rental System](java-car-rental-system/)

A console-based Object-Oriented Programming coursework system organised into four modules: User & Account Management, Fleet & Booking Management, Operations & Billing, and Reporting & Analytics. Fleet & Booking Management was my assigned module. I also implemented substantial portions of the code in the other three modules.

**Technologies:** Java, OOP, package-based modular design, file handling and CSV export.
